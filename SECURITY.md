# Security Policy

BullRun is an educational simulator. It uses virtual money only and does not
connect to any real trading service.

## Known limitations

- Passwords are currently stored as plain text in memory. Hashing is planned as future work.
- User data is not encrypted.

Please do not use real passwords or real financial information in this project.

## Reporting an issue

If you find a security problem, open a GitHub issue or contact the team leader
through GitHub. For anything sensitive, ask for a private channel first and
avoid posting the details publicly.
